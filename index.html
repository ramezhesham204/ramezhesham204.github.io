Used car price prediction at scale

An end-to-end pricing pipeline built on 762,000 vehicle listings, with a custom encoder designed for high-cardinality categorical data.

The problem

Used car pricing depends heavily on categorical fields — make, model, trim, region — many with hundreds or thousands of rare levels. Standard one-hot or mean-target encoding either explodes dimensionality or overfits on sparse categories.

Approach

  • Built a custom hierarchical target encoder that backs off from specific categories (e.g. trim) to broader ones (e.g. model, then make) when a category has too few observations to encode reliably.
  • Trained and tuned an XGBoost regressor on the resulting feature set across the full 762K-row dataset.
  • Wrapped the trained model in a Gradio interface with optional input fields, so predictions remain usable even when a user doesn't know every vehicle spec.

Result

A working pricing tool that handles missing and rare categorical inputs gracefully, rather than failing or defaulting to poor estimates — the kind of robustness a real pricing tool needs, not just a benchmark.

The problem

Hotels lose revenue when bookings cancel unpredictably. The goal was to classify which reservations were likely to be cancelled, using booking, guest, and stay features.

Approach

  • Cleaned and explored the 119K-row booking dataset, then trained and compared classification models for cancellation prediction.
  • Delivered a fully annotated notebook and a 29-slide presentation walking through the analysis end to end.

Catching errors in the reference work

While reviewing the original project materials, I found the arguments to precision_score were passed in the wrong order — silently producing an incorrect metric — and that the write-up claimed SMOTE was used for class balancing when it wasn't actually applied in the code. Catching both meant the final evaluation numbers could actually be trusted.
